ᛉ Plain talk

The things others hide in fine print.

BYOK vs managed, honestly. Solo = you own the API keys and pay providers directly. Assist/Partner = we carry the keys, meter fairly, and include credit — visible in your usage statement.
Model costs never “unlimited”. Fair-use floors protect both of us; heavy automation is quoted before it bills. No surprise invoices.

ᛝ Asked before

What can the agent actually do?

Daily briefs (email, news, calendar), price/listing monitors with alerts, inbox triage, weekly reviews, research digests with citations, document-to-actions extraction, running scripts on your fleet, and anything you wire via its skills system. It messages you on Telegram when something matters.

Is my data private?

Your agent runs on your own VPS (or a dedicated container we operate for you). Memory and sessions live there. We can only reach it when you ask for help — and every session is in your logs.

What's “managed keys” vs “BYOK”?

Solo: you bring API keys from OpenAI/Anthropic/DeepSeek etc. and pay them directly — retail rates, no markup. Assist/Partner: we carry the keys, route across providers for reliability, and include a monthly credit with fair-use metering.

What if you disappear?

Worst case, you keep the server. The agent software is open source (MIT); your configs and memory export in open formats. A new operator can pick it up. We see lock-in as a bug.

Why only 10 founding seats?

So that onboarding hands stay on. Founding members get 50% off for life, a direct line to the founder, and their feedback shapes the roadmap.

Which platforms?

Telegram day one. Discord and the web dashboard are on the Partner tier. Desktop TUI for Windows and macOS on Assist and up.
